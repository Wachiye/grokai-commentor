Fixing 403 Forbidden

A 403 usually means your API key is missing permissions, not that the extension is broken.

  1. Open console.x.ai → API Keys
  2. Create a new key or edit your existing key
  3. Grant permissions: api-key:endpoint:* and api-key:model:*
  4. Ensure your team has billing/credits enabled
  5. Use model grok-4.3 and click Test Connection

Do not use your Grok.com login token — only use an API key from the xAI Console.

How to install

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Click Load unpacked
  4. Select the grokai-extension folder
